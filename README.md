# ミニゲーム (Minigēmu)

Uma aplicação web para compartilhar resultados de jogos diários como Conexo, Expresso, GuessTheGame, Gamedle e Framed.

O progresso pode ser exportado como uma string de backup e restaurado por merge ou substituição.

Atualize os favicons locais dos jogos com `python3 scripts/fetch_favicons.py` ou `just favicons`.
